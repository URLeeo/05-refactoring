ES Modules

How the refactor works

The original token counter logic has been split into three smaller JavaScript modules. Each module has one responsibility, which makes the code easier to read, test, and extend.

utils.js

Contains pure text-processing functions such as cleaning text, counting words, and estimating tokens.

history.js

Owns the snapshot history array and exposes functions for adding, reading, and clearing snapshots.

dom.js

Handles DOM selectors, event listeners, count rendering, and history rendering.
